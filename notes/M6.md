## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude Code | CLAUDE.md loads context automatically; Claude holds the full repo in view and can plan → implement → test in one loop. |
| 5-line helper autocomplete while typing | Copilot | Inline autocomplete at the cursor is Copilot's core strength — no context switch, no prompt, just Tab. |
| Brainstorm three design approaches | Claude.ai chat | Conversational back-and-forth without a repo attached is faster in chat; no need to spin up a CLI session for pure thinking. |
| Review a teammate's PR for security issues | Claude Code (`/code-review`) | Claude Code can read the full diff in context and flag OWASP-style issues; `/code-review` is purpose-built for this. |
| Cross-file refactor with consistent renames | Cursor | Cursor's editor-native multi-file edit mode handles symbol-aware renames across the whole project with fewer round-trips than a CLI. |
| Learning a new library's API | Claude.ai chat | Paste the docs or a snippet and ask questions iteratively — no repo context needed, and chat is faster for pure Q&A. |
