## Bug hunt #1 — SQL injection
- Bug: The query is built with an f-string — `f"SELECT ... LIKE '%{q}%'"` — so user input lands directly in the SQL string. An attacker can inject `%' UNION SELECT username, password FROM users; --` and read arbitrary tables.
- Why Claude wrote it: String-interpolated SQL is everywhere in older tutorials and Stack Overflow answers; it produces correct output for normal inputs, so it looks plausible without thinking about adversarial inputs.
- Fix: Use a parameterized query so the driver escapes the value: `db.session.execute(text("SELECT id, title FROM notes WHERE title LIKE :q"), {"q": f"%{q}%"})` — or use the ORM: `Note.query.filter(Note.title.like(f"%{q}%")).all()`.

## Bug hunt #2 — hallucinated package

- Why Claude wrote it: It sounds like a plausible Flask extension name, and similar fake-sounding packages often appear in tutorials or generated code, so it can be hallucinated when the model guesses based on naming patterns.

## Bug hunt #3 — edge case
- Bug: `sum(ratings) / len(ratings)` raises `ZeroDivisionError` when passed an empty list, because `len([])` is 0.
- Why Claude wrote it: The function works correctly for every non-empty input, so it looks right — Claude doesn't naturally think about the empty-list case unless the prompt mentions it.
- Fix: Guard against the empty case: `return sum(ratings) / len(ratings) if ratings else 0.0`.

## Bug hunt #4 — hardcoded secret
- Bug: The real API key is hardcoded as a string literal — the moment this is committed, the key is in git history forever, even if you delete it in a later commit. Anyone with repo access (or a public repo) can use it.
- Why Claude wrote it: Claude writes working examples and fills in realistic-looking placeholders; it optimizes for "this runs" over "this is safe to commit," and won't stop you unless you ask.
- Fix: Load the key from an environment variable — `api_key=os.environ["OPENAI_API_KEY"]` — and store the value in a `.env` file that's listed in `.gitignore`. If a real key was ever committed, **rotate it immediately** in the OpenAI dashboard; deleting it from the file is not enough.
